# Overview

I created this software to practice using JavaScript. The program is a grade calculator that allows a user to enter assignment names, scores earned, and total points possible. After each assignment is added, the page updates the total earned points, total possible points, current percentage, letter grade, number of assignments, and the last time the summary was updated.

The purpose of writing this software was to strengthen my understanding of JavaScript syntax and common programming concepts. In this project, I practiced using variables, arrays, objects, functions, conditionals, recursion, ES6 array methods, DOM manipulation, and exception handling. I also used a JavaScript library called Day.js to format and display the current date and time.

[Software Demo Video](http://youtube.link.goes.here)

# Development Environment

I used Visual Studio Code to write and edit the code. I used a web browser to run and test the program. The project is made with HTML, CSS, and JavaScript.

The main programming language used for this project is JavaScript. The program also uses the Day.js library to display the date and time in a clean format. JavaScript is used to collect input from the page, store assignment data in an array, calculate grade totals, update the display, and handle invalid user input.
